## 🛠 Troubleshooting

- **Overlay does not appear:** Ensure the game is running in windowed or borderless mode. Press `Tab` or `Insert` again. Check that `process_name` matches your game executable.
- **Game crashes on launch:** Disable any other overlays (Discord, Steam, RTSS) and try again. Run the helper as administrator only if necessary.
- **Hotkeys not working:** Close other applications that capture global hotkeys. Verify `menu_hotkey` in the config file.
- **Antivirus warning:** Some tools may be flagged due to overlay techniques. Add the folder to your exclusions list. Always download from the official source.
